# Study Planner PWA Upgrade

This upgrade adds installable PWA support to the existing Study Planner.

## Upload

Replace the repository's `index.html` with the included version and upload:
- `manifest.webmanifest`
- `sw.js`
- `icons/icon-192.png`
- `icons/icon-512.png`

Do not replace your existing `app.js`, `main.js`, `sync.js`, `style.css`, Firebase workflow, or Firebase config setup.

## Install

### iPhone
Open the GitHub Pages URL in Safari -> Share -> Add to Home Screen -> Add.

### Android
Open the URL in Chrome -> menu -> Add to Home screen / Install app.

Firebase Authentication and Firestore remain unchanged.
